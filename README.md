# 星辉远征录（网页文字探索冒险）

这是一个可在线游玩的**长线奇幻文字冒险**，当前版本重点是：

- 多章节主线（调查遗迹 → 三重材料 → 龙族盟约 → 星门终章）
- 可重复支线（公会委托 / 采集 / 训练）
- 成长系统（等级、经验、生命/魔力上限）
- 背包数量、任务状态、冒险日志
- 存档码导出 / 导入（适合分多次游玩）

> 目标是支持「断断续续玩，总时长 1 小时以上」的体验。

---

## 纯新手：怎么直接玩

### 方式 A：双击运行（最简单）
1. 下载并解压项目 ZIP。
2. 双击 `index.html`。
3. 浏览器打开后就能玩。

### 方式 B：本地启动（推荐）
```bash
python3 -m http.server 8000
```
打开 <http://localhost:8000>

### 方式 C：发布成链接（GitHub Pages）
1. 上传到 GitHub 仓库。
2. `Settings` → `Pages`。
3. Source 选 `Deploy from a branch`。
4. Branch 选 `main`，目录选 `/ (root)`。
5. 保存后等待 1~3 分钟，即可获得在线链接。

## 游戏建议路线（更容易玩到长线内容）

1. 在公会刷 2~3 次委托，先升到 2~3 级。
2. 去森林完成妖精线，拿到 `星尘符文`。
3. 去遗迹拿 `古咒核心`。
4. 去潮汐海湾做神殿试炼，拿 `海潮明珠`。
5. 回村继续训练到 4~5 级，去龙脊峰完成盟约。
6. 前往星门祭台进入终章。
