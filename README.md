# 星辉远征录（网页文字探索冒险）

一个可在线游玩的奇幻文字探索冒险原型，包含：

- 分支剧情与多结局（黯影 / 守护者 / 星辉）
- 角色状态（生命、金币、魔力）
- 背包系统与冒险日志
- 场景插图素材（SVG，可继续替换为 AI 生图）

---

## 纯新手：怎么“直接游玩”

你有 3 种方式，按难度从低到高：

### 方式 A（最简单，不用 GitHub）：直接双击打开

1. 下载项目压缩包（ZIP）。
2. 解压后进入文件夹。
3. 双击 `index.html`。
4. 浏览器里就能玩。

> 适合完全零基础，最快上手。

---

### 方式 B（本地启动，推荐）：一条命令运行

如果你电脑有 Python：

```bash
python3 -m http.server 8000
```

然后打开浏览器访问：

- <http://localhost:8000>

---

### 方式 C（发布到 GitHub，任何人都能在线玩）：GitHub Pages

如果你想“发一个链接给朋友直接玩”，用这个：

1. 把项目上传到你的 GitHub 仓库。
2. 进入仓库页面，点击 **Settings**。
3. 左侧找到 **Pages**。
4. 在 **Build and deployment** 里选择：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`（或你的默认分支）
   - 文件夹选 `/ (root)`
5. 保存后等待 1~3 分钟。
6. GitHub 会给你一个网址，通常像：
   - `https://你的用户名.github.io/仓库名/`
7. 打开这个地址就能在线游玩。

## 新手常见问题

### Q1：我需要会编程才能玩吗？
不需要。玩家只要打开网页点选项即可。

### Q2：我点了没反应怎么办？
先试 `Ctrl + F5` 强制刷新；如果还是不行，换 Chrome/Edge 再试。

### Q3：我可以替换图片吗？
可以，把 `assets/` 下对应的 SVG 换成你的图（同名文件）即可。
