# 星辉远征录（网页文字探索冒险）

一个可在线游玩的奇幻文字探索冒险原型，包含：

- 分支剧情与多结局（黯影 / 守护者 / 星辉）
- 角色状态（生命、金币、魔力）
- 背包系统与冒险日志
- 场景插图素材（SVG，可继续替换为 AI 生图）

## 本地运行

```bash
python3 -m http.server 8000
```

然后打开：<http://localhost:8000>

## 后续可逐渐完善方向

1. 增加更多区域（浮空城、龙巢、海底遗迹）。
2. 加入装备系统、职业技能树、任务系统。
3. 接入后端存档（账号进度、排行榜）。
4. 用 AI 生图/图像模型替换 `assets/*.svg` 插图素材。
